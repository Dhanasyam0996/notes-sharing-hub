# Smart Study Resource & Notes Sharing Hub

A full-stack college project built using **React.js** (Frontend) and **Django REST Framework** (Backend), configured for deployment on **Vercel**.

## Features
- Search and filter notes by Subject, Semester, and Department.
- Upvote useful study materials.
- Direct external links to PDFs/documents (Google Drive, Supabase, Cloudinary).
- Add new notes via a modal popup.
